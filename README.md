# 巴利语学习 App · 第一版首页原型

这是一个可直接部署到 GitHub Pages 的静态 PWA 原型，不需要账号、服务器或云端数据库。

## 当前包含
- Tinder 式卡片首页。
- 右滑 / 右侧按钮 = 认识；左滑 / 左侧按钮 = 不认识。
- 点击卡片或详情按钮打开滚动详情页。
- 撤销上一步。
- 学习状态保存在 IndexedDB。
- Service Worker 离线缓存。
- 3 张仅用于交互测试的演示词卡。

## 重要说明
- 当前是首页交互原型，不是完整课程。
- 演示词卡的内容是简要教学草稿；正式经文、词源、词形和语料例句将在内容制作阶段逐条核验。
- 本版本尚未接入正式备份模块、生词本、复习队列、批量导入和语义网络。
- 清除浏览器网站数据仍会清除本机学习状态；正式备份模块会在后续合并并重新实测。

## 部署
将本文件夹内所有文件上传到 GitHub Pages 仓库根目录，Pages 设置为 `main` 分支、`/(root)`。
